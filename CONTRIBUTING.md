# Cómo contribuir a ML-Threat-Dashboard

¡Gracias por tu interés en contribuir! 

1. Haz un fork del repositorio.
2. Crea una rama para tu funcionalidad (`git checkout -b feature/nueva-grafica`).
3. Haz commit de tus cambios (`git commit -m 'Añade nueva gráfica de predicciones'`).
4. Haz push a la rama (`git push origin feature/nueva-grafica`).
5. Abre un Pull Request utilizando nuestra plantilla.

Por favor, asegúrate de levantar el proyecto localmente usando Docker (lee `DOCKER_SETUP.md`) antes de enviar cambios.
