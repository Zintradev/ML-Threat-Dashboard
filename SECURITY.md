# Security Policy

## Supported Versions

Currently, only the latest version of the **ML-Threat-Dashboard** is supported with security updates. 

Because this project relies on modern machine learning and web frameworks (Python 3.13+, Scikit-learn 1.8+, Node 22+), we strongly recommend keeping your local deployment synchronized with the latest commits on the `main` branch to ensure all dependencies are free of known vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| `main` (Latest) | :white_check_mark: |
| Legacy (Python 3.9) | :x:                |

## Reporting a Vulnerability

Security is a top priority for this project. If you discover a security vulnerability within the ML-Threat-Dashboard, please follow responsible disclosure practices.

### How to report:
1. **Do NOT open a public GitHub issue.** Publicly disclosing a vulnerability before a patch is available can put other users at risk.
2. **Contact the maintainer directly:** Please send an email to `[TU_EMAIL@EJEMPLO.COM]` with the subject line `[SECURITY] Vulnerability Report`.
3. **Provide details:** Please include:
   * A clear description of the vulnerability.
   * Step-by-step instructions to reproduce it.
   * The potential impact or risk.

### What to expect:
* You will receive an acknowledgment of your report within **48 hours**.
* We will prioritize the investigation and work on a fix immediately.
* You will be kept informed of our progress.
* Once the vulnerability is resolved and patched, you will be credited for the responsible disclosure (unless you prefer to remain anonymous).

Thank you for helping to keep the ML-Threat-Dashboard safe!
